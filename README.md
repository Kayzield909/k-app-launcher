# Aatrox launcher

A home-screen app (PWA) that opens the Aatrox Capital dashboard and related pages. It holds links only: no holdings, prices or keys. Every linked page needs your own sign-in.

Install on Android: open https://kayzield909.github.io/k-app-launcher/ in Chrome, then ⋮ → Install app (or Add to Home screen). Long-press the icon for shortcuts: Dashboard, Trading 212 sync, Signal log, Trading 212.

Hosted with GitHub Pages from the `main` branch root.
